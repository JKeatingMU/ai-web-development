Resources

Tools, documentation, and references used throughout the course.

1 Getting Started

Setup Guide
setup-guide.html
Cross-platform setup for Node.js, PostgreSQL, and the demo app. Start here.
Node.js
nodejs.org
JavaScript runtime for the server. Download the LTS (Long-Term Support) version.
PostgreSQL
postgresql.org
The relational database used throughout the backend track.
Railway
railway.app
Deployment platform for the API and database. Covered in B7.
Git
git-scm.com
Version control — download and install Git for your platform here.

2 AI Tools

Claude
claude.ai
Used as the primary AI partner in B1 prompt engineering examples. Strong at explaining generated code.
ChatGPT
chatgpt.com
Alternative AI assistant. All four prompt types (Scaffold/Explain/Debug/Extend) work across any tool.
GitHub Copilot
github.com/copilot
In-editor AI completion. Useful for the B2–B5 series when you are working in VS Code.
Cursor
cursor.sh
AI-first code editor. A strong choice for the extend and debug prompt types in B1.

3 Official Documentation

MDN Web Docs
developer.mozilla.org
The canonical reference for HTML, CSS, JavaScript, and HTTP. Bookmark this.
Node.js Docs
nodejs.org/docs
Full API reference for Node's built-in modules (fs, path, http, crypto, etc.).
Express
expressjs.com
The web framework used in Tracks B and D. Routing, middleware, and error handling reference.
React
react.dev
Official React documentation including hooks reference. Used in Track C.
PostgreSQL Docs
postgresql.org/docs
SQL syntax, data types, and psql reference. Especially useful for B5 (JOINs, pagination).
JWT.io
jwt.io
Interactive JWT debugger and specification reference. Used in B3 (Authentication).

4 Developer Tools

curl
curl.se
Command-line HTTP client. Pre-installed on macOS and Linux; see curl.se for Windows. Core tool in B4.
jq
jqlang.github.io/jq · jqplay.org
Command-line JSON processor. Pairs with curl in B4. Use jqplay.org to experiment without installing.
Git
git-scm.com
Version control. Pro Git book is free at git-scm.com/book — essential reading for A3.
GitHub CLI
cli.github.com
Create PRs, manage issues, and interact with GitHub from the terminal. Useful in A3.
Postman
postman.com
GUI-based API client. An alternative to curl if you prefer a visual interface for testing.

5 AI Automation

n8n
n8n.io
Open-source workflow automation with a built-in AI Agent node. The core tool for Track E.
Sliplane
sliplane.io
Hosting provider for self-hosted n8n instances. Used in Track E for deployment.
Claude API / Anthropic
anthropic.com
API access to Claude models. Used in E4 and E5 when calling AI from within n8n workflows.

6 Learning Supplements

MDN Learn Web Development
developer.mozilla.org/en-US/docs/Learn
Structured learning track covering HTML, CSS, and JavaScript from the ground up. Complements Track A.
The Odin Project
theodinproject.com
Free, project-based full-stack curriculum. Strong complement to Tracks A, B, and C.
freeCodeCamp
freecodecamp.org
Free certifications in JavaScript, APIs, SQL, and more. Useful for reinforcing Track B concepts.
PostgreSQL Tutorial
postgresqltutorial.com
Practical, example-driven SQL and PostgreSQL guide. Pairs well with A4 and B5.
