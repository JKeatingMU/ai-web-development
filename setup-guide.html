Local Setup Guide

Everything you need to run the Reading List API on your own machine.

macOS Windows Linux Node.js 20+ PostgreSQL 15+

1 Install Node.js

We need Node.js v20 or later. The recommended approach uses nvm (Node Version Manager) so you can switch versions easily. Windows has its own nvm port.

Option A — nvm (recommended)

Terminal
# Install nvm $ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash # Restart your terminal, then install Node 20 $ nvm install 20 $ nvm use 20

Option B — Direct installer

Download the macOS installer from nodejs.org → choose the LTS version (20.x). Run the .pkg file and follow the prompts.

Note on Homebrew You can also use brew install node@20 if you already have Homebrew. However, nvm or the direct installer work the same and don't require Homebrew.

Option A — nvm-windows (recommended)

Download the installer from github.com/coreybutler/nvm-windows — grab nvm-setup.exe from the latest release.

Command Prompt or PowerShell (as Administrator)
After installing nvm-windows: > nvm install 20 > nvm use 20

Option B — winget

Command Prompt or PowerShell (as Administrator)
> winget install OpenJS.NodeJS.LTS

Option C — Direct installer

Download the Windows installer from nodejs.org → LTS version → .msi file. Run it and accept all defaults.

PowerShell execution policy If you see a "scripts are disabled" error, run PowerShell as Administrator and execute: Set-ExecutionPolicy RemoteSigned

Option A — nvm (recommended)

Terminal
# Install nvm $ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash # Reload shell config, then install Node 20 $ source ~/.bashrc # or ~/.zshrc if using zsh $ nvm install 20 $ nvm use 20

Option B — NodeSource APT repository (Ubuntu/Debian)

Terminal
$ curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - $ sudo apt-get install -y nodejs
Avoid apt's default Node sudo apt install nodejs on Ubuntu often installs an old version (v12 or v18). Use nvm or the NodeSource repo to get v20.
Verify — run this in any terminal:
$ node --version v20.x.x # any 20.x is fine $ npm --version 10.x.x

2 Install PostgreSQL

We need PostgreSQL 15 or later. The installation method varies significantly by platform.

Postgres.app (recommended — easiest)

Download from postgresapp.com. Drag to Applications and open it. Click Initialize. PostgreSQL is now running.

Add the command-line tools to your PATH — copy this into your terminal:

Terminal
$ sudo mkdir -p /etc/paths.d $ echo /Applications/Postgres.app/Contents/Versions/latest/bin \ | sudo tee /etc/paths.d/postgresapp # Restart terminal, then verify: $ psql --version psql (PostgreSQL) 16.x
Postgres.app advantages Runs as a menu bar app — easy to start/stop. No admin password needed. Creates a database named after your username automatically (used as the default connection).

EDB Installer (official)

Download from postgresql.org/download/windows — click Download the installer (EDB). Run the .exe and follow the wizard.

During installation:

  • Choose a password for the postgres superuser — remember this
  • Keep the default port: 5432
  • Keep the default locale
  • The installer adds psql and other tools to your PATH automatically
Starting PostgreSQL After installation, PostgreSQL runs as a Windows service and starts automatically. To check: open Services (search in Start menu) and look for postgresql-x64-16 — it should show "Running".
Command Prompt
# Connect as the postgres superuser to verify > psql -U postgres # Enter the password you chose during installation psql (16.x) postgres=# \q

apt (Ubuntu/Debian)

Terminal
$ sudo apt update $ sudo apt install -y postgresql postgresql-contrib # Start the service $ sudo systemctl start postgresql $ sudo systemctl enable postgresql # start on boot # Create a user matching your login name (makes psql easier) $ sudo -u postgres createuser --superuser $USER $ sudo -u postgres createdb $USER

dnf/yum (Fedora/RHEL/CentOS)

Terminal
$ sudo dnf install -y postgresql-server postgresql-contrib $ sudo postgresql-setup --initdb $ sudo systemctl start postgresql $ sudo systemctl enable postgresql
Verify — you should be able to connect:
$ psql --version psql (PostgreSQL) 15.x or 16.x $ psql # connects using your system username (macOS/Linux) > psql -U postgres # Windows — connect as postgres superuser

3 Get the Demo App Files

The demo app is a folder called crud-demo provided by your instructor. You should have these files:

reading-list-api/ ├── package.json project config + dependencies ├── .env.example environment variable template ├── schema.sql database table definitions ├── db.js PostgreSQL connection pool ├── auth.js register and login routes ├── middleware/ │ └── authenticate.js JWT verification middleware └── server.js Express app + all routes
If you received a ZIP file Right-click → Extract All (Windows) or double-click (macOS/Linux) to unzip it. Open a terminal and navigate into the extracted folder.
All platforms — navigate to the app folder
# Navigate into the app folder (adjust the path to where you extracted it) $ cd reading-list-api # Confirm you can see the files $ ls # macOS / Linux > dir # Windows Command Prompt > ls # Windows PowerShell

4 Create the Database

Terminal
# Create a new database called reading_list $ createdb reading_list # Run the schema (creates the tables) $ psql reading_list < schema.sql # Verify the tables were created $ psql reading_list -c "\dt" List of relations Schema │ Name │ Type │ Owner ────────┼──────────┼───────┼─────── public │ books │ table │ ... public │ users │ table │ ...
Command Prompt
# Connect as postgres superuser and create the database > psql -U postgres -c "CREATE DATABASE reading_list;" # Run the schema file (adjust path if needed) > psql -U postgres -d reading_list -f schema.sql # Verify the tables > psql -U postgres -d reading_list -c "\dt"
Windows connection string Your DATABASE_URL in the next step will need to include the postgres password: postgresql://postgres:YOURPASSWORD@localhost:5432/reading_list

5 Configure the Environment

Copy the example file and fill in your values:

Terminal
$ cp .env.example .env
Command Prompt
> copy .env.example .env

Now open .env in any text editor (VS Code, Notepad, nano, etc.) and set the values:

# .env — fill these in DATABASE_URL=postgresql://localhost/reading_list # macOS (Postgres.app): postgresql://localhost/reading_list # Linux: postgresql://localhost/reading_list # Windows: postgresql://postgres:YOURPASSWORD@localhost:5432/reading_list PORT=3001 JWT_SECRET=replace-with-a-long-random-string-at-least-32-characters
Generating a good JWT_SECRET
# macOS / Linux — generates 32 random bytes as hex $ node -e "console.log(require('crypto').randomBytes(32).toString('hex'))" # Windows PowerShell > node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
Paste the output as the value for JWT_SECRET. Never commit your .env file.

6 Install Dependencies & Start the Server

All platforms
# Install Node.js packages $ npm install # Start the server in development mode (auto-restarts on file changes) $ npm run dev # You should see: Server running on port 3001
Verify it's working — open a new terminal tab and run:
$ curl -s http://localhost:3001/api/health {"status":"ok"}
If you see {"status":"ok"} — you're all set.
Windows without curl curl is included in Windows 10/11. If it's not found, use PowerShell's Invoke-WebRequest:
Invoke-WebRequest -Uri http://localhost:3001/api/health | Select-Object -ExpandProperty Content
Or install curl from curl.se/windows.

? Common Problems

Error messageLikely causeFix
command not found: node Node not installed, or nvm not loaded Restart your terminal. If using nvm: nvm use 20. Otherwise re-install Node.
command not found: psql PostgreSQL CLI tools not on PATH macOS: add Postgres.app to PATH (Step 2). Windows: re-run installer, check "Add to PATH". Linux: sudo apt install postgresql-client
EADDRINUSE: address already in use :::3001 Another process is on port 3001 macOS/Linux: lsof -ti:3001 | xargs kill — Windows: netstat -ano | findstr 3001 then taskkill /PID [number] /F
Connection refused (PostgreSQL) PostgreSQL service not running macOS: click the Postgres.app elephant icon → Start. Linux: sudo systemctl start postgresql. Windows: start the service in Services.
password authentication failed Wrong username/password in DATABASE_URL Check your .env DATABASE_URL. Windows users must include the postgres password.
relation "books" does not exist schema.sql hasn't been run Re-run Step 4: psql reading_list < schema.sql
MODULE_NOT_FOUND npm install not run, or run in wrong folder Make sure you're inside the reading-list-api folder, then run npm install
Cannot use import statement Node version too old (pre-14) Run node --version — must be 14+. Use nvm to upgrade: nvm install 20 && nvm use 20
