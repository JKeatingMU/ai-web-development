This course pairs hands-on building with deliberate reflection. At every step you use AI to generate code — then you read it, question it, and understand it. The goal is not to produce software faster. It is to become the developer who can evaluate, fix, and extend what AI produces.

Every module ends with a prompt reflection exercise — a structured pause to consider what the AI did, why, and what you would change next time.

By the end of this course, you will be able to:

  1. 01Explain how the web works — HTTP, DNS, status codes, request-response — and trace a request from browser to database
  2. 02Use the terminal confidently: navigate the filesystem, compose shell pipelines, manage environment variables, and write shell scripts
  3. 03Track and share code using Git and GitHub, including branching, pull requests, and publishing via GitHub Pages
  4. 04Design relational database schemas, write SQL queries, apply constraints and JOIN operations, and manage schema evolution safely
  5. 05Build a fully functional REST API from scratch using Node.js, Express, and PostgreSQL, with authentication via JWT
  6. 06Apply prompt engineering strategies — Scaffold, Explain, Debug, Extend — to direct AI assistants effectively at each stage of development
  7. 07Read and evaluate AI-generated code critically: identify patterns, security risks, and design tradeoffs rather than accepting output blindly
  8. 08Deploy a working server-side application to a cloud platform with proper environment configuration and database integration

How these decks work

Each module is an interactive HTML deck, not a slideshow export or a PDF. That is deliberate: it lets the material respond to you, remember where you are, and adapt to how you need to read it.

Built for learning

  • Checkpoint quizzes — short questions mid-deck that surface what has not landed yet, with a jump back to the relevant slide
  • Notes on any slide — saved in your browser and kept as you move through the deck
  • Narrated walkthroughs — optional audio with the relevant part of each slide highlighted as it is discussed
  • Hands-on tasks and a prompt-reflection exercise — built into every module
  • Progress is saved — close the tab and pick up where you left off; works offline once loaded

Accessibility & adaptability

  • Adjustable text size — A− / A+ (top-right, on this page and in every deck) enlarges the text and the layout reflows so nothing is cut off; your choice is remembered
  • Light and dark themes
  • Full keyboard control — ← → or Space to move, Home / End to jump, F for fullscreen, Tab to every control
  • Screen-reader support — each slide is announced with its position and heading, with a skip link straight to the content
  • Respects reduced-motion — animation is dropped when your system asks for it
  • No meaning carried by colour alone — and a high-contrast palette in both themes
  • Accessible text versions — plain, linear pages that work with full browser zoom and screen readers. This home page has one (course outline →), as do individual modules.
